Giới thiệu môn học

Môn học Lập trình Web cung cấp cho sinh viên những kiến thức nền tảng và kỹ năng cần thiết để xây dựng các ứng dụng web hiện đại. Sinh viên sẽ được học về HTML, CSS, và JavaScript, cũng như các thư viện và framework phổ biến như Bootstrap và React.

Mục tiêu môn học

  • Hiểu rõ các khái niệm cơ bản của công nghệ web.
  • Xây dựng được giao diện web tĩnh bằng HTML và CSS.
  • Sử dụng JavaScript để tạo ra các trang web có tính tương tác.
  • Làm quen với các công cụ phát triển web hiện đại.

Đề cương chi tiết

Nội dung: Giới thiệu môn học, lịch sử web, các công nghệ cơ bản.

Nội dung: Các thẻ HTML cơ bản, cấu trúc một trang HTML.
