Design Style Reference

Tài liệu này mô tả style của design để AI khác có thể bám theo. Nguồn: ảnh reference bên dưới.

1. Reference image (design cần bám theo)

2. Hướng dẫn cho AI

Khi nhận file HTML này cùng ảnh reference:

  • Xem ảnh ở mục 1 để nắm layout, màu sắc, font chữ, khoảng cách, thành phần giao diện.
  • Áp dụng hoặc cập nhật các design tokens ở mục 3–6 cho đúng với ảnh.
  • Khi tạo UI mới, dùng đúng palette, typography, spacing và component style đã mô tả.

3. Color palette

Mô tả màu chính trong design (cập nhật theo ảnh reference):

--color-primary
Màu nhấn (CTA, link, accent): #2563eb
--color-secondary
Màu phụ: #64748b
--color-background
Nền trang: #ffffff
--color-surface
Nền card/panel: #f8fafc
--color-text
Chữ chính: #0f172a
--color-text-muted
Chữ phụ: #64748b
Cập nhật các giá trị trên cho khớp với ảnh reference. Thêm màu khác (border, success, error…) nếu có trong design.

4. Typography

--font-primary / --font-heading
Font chữ chính và tiêu đề (từ ảnh): system-ui, -apple-system, sans-serif
Kích thước / line-height
Heading: lớn rõ ràng; body: ~1rem–1.125rem, line-height ~1.5–1.6. Cập nhật cụ thể theo ảnh.

5. Spacing & border radius

--space-unit
Đơn vị spacing cơ sở: 8px. Padding/margin thường là bội số (8, 16, 24, 32…).
--radius-sm / --radius-md / --radius-lg
Bo góc: 4px, 8px, 12px. Cập nhật theo ảnh.
